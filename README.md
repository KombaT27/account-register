Account Register Demo

Das ist eine vereinfachte Version von meinem Register System.

Der Service laeuft getrennt und uebernimmt Registrierung und Captcha.

Funktionen

Captcha wird erzeugt und geprueft
Registrierung ueber Socket Verbindung
Passwort wird nicht im Klartext gespeichert
Schutz gegen zu viele Anfragen

Hinweis

Das ist nur eine Demo Version ohne komplette Integration.
