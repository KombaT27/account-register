Account Register Demo

Das ist eine abgespeckte Version von meinem Register System.

Der Service ist getrennt aufgebaut und verarbeitet Anfragen eigenständig.

Funktionen

Captcha wird erzeugt und geprüft  
Registrierung über einfache Request Verarbeitung  
Passwort wird nicht im Klartext gespeichert  
Grundlegender Schutz gegen fehlerhafte Eingaben  

Ablauf

Anfrage wird eingelesen und geparst  
Je nach Befehl wird Logik ausgeführt  
Ergebnis wird zurückgegeben  

Hinweis

Die Demo ist bewusst reduziert.
Im Original System sind zusätzlich Logging, Rate-Limits und Datenbankanbindung vorhanden.
